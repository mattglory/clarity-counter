\# 🤝 Contribution Guidelines



Thank you for your interest in contributing to \*\*Clarity Counter\*\*!



This project is part of the Stacks monthly rewards program. To qualify for grant eligibility:



\## ✅ What Counts as a Valid PR



\- Add meaningful Clarity functionality

\- Improve contract security or performance

\- Add or improve test coverage

\- Refactor for clarity or maintainability

\- Add UI integration or enhancements



\## ❌ What Doesn’t Count



\- Cosmetic changes (e.g. formatting, styling)

\- README-only edits

\- Auto-generated code from templates



\## 🧾 How to Submit



1\. Fork the repo

2\. Create a new branch (e.g. `feature/improve-access-control`)

3\. Make your changes

4\. Submit a pull request to `main`

5\. Include a short description of what you improved



Once submitted, your PR will be reviewed and counted toward monthly STX rewards.
